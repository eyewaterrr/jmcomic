## 已确定

| 项目 | 结论 |
| --- | --- |
| 频道文件读写 | Telethon 走 MTProto，并行分块上传 |
| 书库位置 | 私有频道（书库频道） |
| 收藏格式与位置 | PDF（JPEG 质量 85），发到第二个私有频道（精选频道）；不用外部存储 |
| 多章节作品 | 默认所有章节一起入库，一章一个文件 |
| 使用者 | 目前只有所有者；所有者可以在 Bot 里增删用户 |
| 阅读器 | 自研 Mini App，默认上下滑动，可切换成左右翻页 |
| 阅读页网址 | `jm.<域名>`，复用现有 nginx 和 Cloudflare 源站证书 |
| 页面缓存上限 | 1GB |
| 下载画质 | 解码后的图片按 WebP 质量 90 保存（jmcomic 默认是 80） |

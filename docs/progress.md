## 已确定

| 项目 | 结论 |
| --- | --- |
| 入库、书库频道 | 取消。书库频道不再读写，已有帖子留着不动 |
| 阅读的数据来源 | 打开时由服务器从 JM 取原图，边下边看，存在服务器缓存里；手机上用 Canvas 还原 |
| 服务器缓存 | 上限 2GB；7 天没打开的章节删除；超过上限时按最久没打开的先删；预读往后 20 页 |
| 收藏 | 只记收藏夹（包括 JM 同步的“JM·”收藏夹），不触发下载、PDF 或任何任务 |
| 上传精选 | 单独的按钮和任务：PDF（JPEG 质量 85，300MB 分卷）发到精选频道 |
| 数据库备份 | 由服务器整机备份负责，服务不再往 Telegram 发备份 |
| 远程下载机 | 删除代码和部署脚本（代码留在 git 历史里） |
| 旧数据 | `chapters` 留作章节信息（含每页尺寸），`pages` 表删除 |
| v1.1 只入库的作品 | 迁移时放进所有者的默认收藏夹 |
| 图片的浏览器缓存 | `max-age` 24 小时，网址里不带令牌，跨会话也能命中 |
| 使用者 | 目前只有所有者；所有者可以在 Bot 里增删用户；收藏夹按用户分开 |
| 阅读器 | 自研 Mini App，默认上下滑动，可切换为左右翻页 |
| jmcomic 版本 | `>=2.7.10,<3`，同一大版本内自动升级 |
| 反向同步到 JM | 默认关闭，开关由所有者在 `/jmsync` 里控制；只加不删 |

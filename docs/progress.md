## 已确定

| 项目 | 结论 |
| --- | --- |
| 频道文件读写 | Telethon 走 MTProto，并行分块上传 |
| 书库位置 | 私有频道（书库频道） |
| 收藏 | 作品在任意一个收藏夹里就算收藏；收藏后自动生成 PDF（JPEG 质量 85），发到精选频道；取消收藏不删 PDF |
| JM 收藏夹 | 单向镜像成“JM·<名字>”收藏夹；不影响自建收藏夹 |
| 多章节作品 | 默认所有章节一起入库，一章一个文件 |
| 使用者 | 目前只有所有者；所有者可以在 Bot 里增删用户；收藏夹按用户分开 |
| 阅读器 | 自研 Mini App，默认上下滑动，可切换为左右翻页 |
| 阅读页网址 | `jm.<域名>`，复用现有 nginx 和 Cloudflare 源站证书 |
| 页面缓存上限 | 1GB |
| 下载画质 | 解码后的图片按 WebP 质量 90 保存（jmcomic 默认是 80） |
| jmcomic 版本 | `>=2.7.10,<3`，同一大版本内自动升级 |
| `/jmsync` | 保持现状：同步的作品放进“JM·”收藏夹，等于收藏，会生成 PDF。不加“只入库”选项；只想入库时用 `enqueue-batch` |
| 反向同步到 JM | 有这个功能，默认关闭，开关由所有者在 `/jmsync` 里控制；只加不删 |
| 分布式下载 | 不做，维持单机后台排队；需要更快时给本机加 CPU 核心（见 environment.md 第 9 节） |
